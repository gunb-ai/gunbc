### Instrument rules learned this session (each one cost something; keep enforcing them)
- LOCAL GATE BEFORE EVERY DISPATCH of an injected helper: scratch instruments/stubcheck.py typechecks it
  with rustc against a stub carrying the REAL field sets (Node, InferredNode, Connective, Cardinality,
  SourceSpan, TextJudgment, TextRepresentation, TypeEnv incl. RECURSIVE parents) plus the real emitted fn
  signatures, and reproduces the anchor's context (loop/if-else) so `break` is legal. It paid for itself
  three times: `%s` in an emitted-Rust format string (%s is the DAG surface's interpolation), a missing
  module_path on my stub, and the Rc<TypeEnv> Debug hazard below. Without it each was a 21-minute dispatch.
- NEVER `{:?}` a TextJudgment/Rc<TypeEnv>: TypeEnv carries bindings + str_bindings + ancestry_str_bindings
  + source_indices for EVERY file + intern_table + symbol_index + parents: Rc<Vec<Rc<TypeEnv>>> RECURSIVELY
  (v1_compiler_infer_env.rs:69-84). Printed 208 times it is an unreadable log. Print env.module_path only.
  I KILLED a running dispatch at 10 min on discovering this rather than waiting out 27 min for a log I
  knew was unusable.
- NEVER filter a build's output in a dispatch script (a `grep | tail -3` swallowed 6 compile errors and
  the spans, turning a one-line type error into a lost round trip). Build output goes to a file whole and
  is printed in full on failure.
- Ship the logs BEFORE exiting on every failure path (an `exit 7` that tarred nothing lost the one
  diagnostic I needed and cost a second 60-min dispatch).
- PROVE the probe is in the EMITTED seed before the 30-min self-host (grep the marker in the seed).
- An unparseable row is its own bucket, never a silent default: my first parser read "0 rows" from a
  greedy regex and that must NEVER be read as "0 refusals"; a head_of() keyed on the printed shape's
  first word reported Bucket B EMPTY because a Disj prints as Coproduct(<name>) -- a false negative on
  the exact measurement the instrument existed to take.
- Carrier SHAs must be pinned AND cross-checked: two carrier heads can differ only in the patcher while
  the .dag carriers stay byte-identical (verified 5aed2d5e.../60a3ee90...) -- say which head a measurement
  used, and never fetch a carrier that lacks the patcher.
- grep -c counts LINES not occurrences; under BRE `\|` is alternation so `grep -ac '\|a=b'` matches every
  line -- use grep -aF for fixed-string tallies (this bug made every outcome tally read 208).
