  `cp -m 0755 src staged_path`; NO ownership check.

  atomic per identity; takes `launched: AttemptGate` (produced by compute_open_attempt +

  only expressible by driving the two REAL halves of compute_spawn_and_collect directly:
  compute_run_unit(A) ; compute_run_unit(B) ; compute_return_outputs(layout_A).
  (A single compute_spawn_and_collect(A) call cannot be interleaved with B by its caller.)
  This matches the amendment wording "drives compute_spawn_and_collect -> compute_run_unit
  -> compute_return_outputs ... It runs below compute_reserve."

  via cargo:rustc-env => env!() into the binary. build.rs WATCHES the worktree HEAD file
  (rerun-if-changed) => a different commit re-stamps + recompiles. Two worktrees
  A@HEAD vs B@HEAD~1 => different source trees => different baked identities =>
