Interpretation
--------------

execution oracle for v4 substrate yet. Phase 2 testing that requires
evaluating v4 programs + TestClaims must wait on **T-22 (v4 compiler/05_eval
and claim runner)** — dissolution trigger for an automated `v2-compiler run`
TestClaim CI lane.

remains **`dsl/std/process.dag`** only (P2 single authority). A prior test-only
shim was removed once it had zero consumers; reintroduce only with an explicit
Practice-4 receipt **and** a real `dag run` entry consumer, or after T-22 when
v4 owns eval without cross-root duplication.
