# Bootstrap Meta-Modeling: Structural Makefile & Gitignore Generation

**Status**: Draft
**Date**: 2026-01-30

## Goal

Replace hardcoded Makefile and .gitignore generation in `bootstrap` with structural generation based on meta-modeling, similar to how `makegen` uses `ToolRegistry` and `BuildConfig`.

## Current State

### Bootstrap (Hardcoded)

`lib/tools/bootstrap/src/ops.rs`:

```rust
fn execute_generate_makefile(_inputs: HashMap<String, Value>) -> Result<...> {
    let makefile = r#"# Generated by gunbc-bootstrap
.DEFAULT_GOAL := help
.PHONY: help build test lint ci gist buck2 makegen deps bootstrap

help:
    @echo "gunbc - DAG-based code generation framework"
    ...
"#;  // All hardcoded!
    Ok(outputs)
}

fn execute_generate_gitignore(_inputs: HashMap<String, Value>) -> Result<...> {
    let gitignore = r#"# Generated by gunbc-bootstrap
/target/
*.swp
...
"#;  // All hardcoded!
    Ok(outputs)
}
```

**Problems**:
- No reuse of `ToolRegistry` — tool names hardcoded
- No reuse of `BuildConfig` — commands hardcoded
- .gitignore patterns not derived from project structure
- Duplication with makegen

### Makegen (Meta-Modeled)

`lib/tools/makegen/src/registry.rs`:

```rust
pub struct ToolRegistry {
    pub tools: Vec<ToolInfo>,
    pub meta_targets: Vec<MetaTarget>,
}

pub struct BuildConfig {
    pub build_command: Vec<&'static str>,
    pub test_command: Vec<&'static str>,
    pub lint_command: Vec<&'static str>,
    ...
}
```

`lib/tools/makegen/src/render.rs`:

```rust
pub fn render_makefile(registry: &ToolRegistry) -> String {
    MakefileRenderer::new(registry).render()
}
```

**Strengths**:
- Tools registered declaratively
- BuildConfig is single source of truth
- Makefile generated from registry data

## Target Design

### 1. Unify Bootstrap and Makegen

Bootstrap should use the same `ToolRegistry` and `BuildConfig` as makegen, not hardcoded strings.

**Option A: Bootstrap uses makegen library**

```rust
// lib/tools/bootstrap/src/ops.rs
use gunbc_makegen::{ToolRegistry, BuildConfig, render_makefile, render_gitignore};

fn execute_generate_makefile(_inputs: HashMap<String, Value>) -> Result<...> {
    let registry = ToolRegistry::default_registry();
    let config = BuildConfig::cargo();
    let content = render_makefile(&registry, &config);
    // ...
}
```

**Option B: Share registry crate**

Extract `ToolRegistry` and `BuildConfig` to a shared `gunbc-meta` or `gunbc-registry` crate.

### 2. Add GitignoreRenderer

### 3. Meta-Model for Gitignore Patterns

```rust
#[derive(Debug, Clone)]
pub struct LanguageIgnorePatterns {
    pub name: &'static str,  // "rust", "python", etc.
    pub patterns: Vec<&'static str>,
}

impl LanguageIgnorePatterns {
    pub fn rust() -> Self {
        Self {
            name: "rust",
            patterns: vec![
                "/target/",
                "**/*.rs.bk",
                "Cargo.lock",  // Or not, depending on project type
            ],
        }
    }
    
    pub fn python() -> Self {
        Self {
            name: "python", 
            patterns: vec![
                "__pycache__/",
                "*.pyc",
                ".venv/",
                "*.egg-info/",
            ],
        }
    }
}
```

### 4. Project Structure Derivation

Gitignore can derive patterns from project structure:

```rust
impl GitignoreConfig {
    pub fn from_workspace(registry: &ToolRegistry, workspace: &WorkspaceInfo) -> Self {
        let mut config = Self::default();
        
        // Add buck-out if using buck2
        if registry.tools.iter().any(|t| t.short_name == "buck2") {
            config.build_patterns.push("buck-out/");
        }
        
        // Add generated file markers
        for tool in &registry.tools {
            if tool.generates_files {
                config.project_patterns.push(format!("# Generated by {}", tool.short_name));
            }
        }
        
        config
    }
}
```

## Implementation Plan

### Phase 1: Make Bootstrap Use Makegen Registry

1. Add `gunbc-makegen` as dependency to `gunbc-bootstrap`
2. Replace hardcoded Makefile with `render_makefile(&registry)`
3. Verify bootstrap generates same/better Makefile

### Phase 2: Add GitignoreRenderer to Makegen

1. Create `GitignoreConfig` struct in makegen
2. Create `GitignoreRenderer` implementing `Renderable`
3. Add `render_gitignore()` function
4. Add language pattern presets (Rust, etc.)

### Phase 3: Update Bootstrap to Use GitignoreRenderer

1. Replace hardcoded gitignore with `render_gitignore()`
2. Add any bootstrap-specific patterns (derived from workspace scan)

### Phase 4: (Optional) Extract to Shared Crate

If multiple tools need registry/config:
1. Create `gunbc-meta` crate
2. Move `ToolRegistry`, `BuildConfig`, `GitignoreConfig`
3. Update makegen, bootstrap, ci to use shared crate
