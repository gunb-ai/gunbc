# TODO — Design Plans

Design plans for upcoming features. When complete, move to `TODONE/`.

Each plan should have:
1. **Goal** — What we're trying to achieve
2. **Design** — Architecture, data models, diagrams
3. **Tasks** — Checkboxes for implementation steps

## Template

```markdown
# [Feature Name]

**Status**: Draft | In Progress | Completed
**Date**: YYYY-MM-DD

## Goal

[What we're trying to achieve]

## Design

[Architecture, data models, diagrams]

## Tasks

- [ ] Task 1
- [ ] Task 2
- [ ] Task 3

## Notes

[Implementation notes, decisions made]
```
