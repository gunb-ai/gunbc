PRIVILEGED WRITE 1 — set temp admin password over the in-band SSIF channel (classify in privileged_effect_census):
  `ipmitool user set password 1 '0penBmc'`         -> IPMI "Invalid data field in request"
  `ipmitool user set password 1 '0penBmc' 20`      -> same (OpenBMC 3.22 policy: published 7-char factory
                                                       password is rejected; min length >= 8).
  `ipmitool user set password 1 '<temp 20-char>' 20` -> "Set User Password command successful (user 1)"
  Out-of-band verify: GET https://192.168.1.250/redfish/v1/Managers/bmc with root/<temp> -> HTTP 200 (FirmwareVersion 3.22.00).

  POST .../Actions/Manager.ResetToDefaults {"ResetType":"ResetAll"}         -> HTTP 400 (ResetToDefaultsType required)
  POST .../Actions/Manager.ResetToDefaults {"ResetToDefaultsType":"ResetAll"} -> HTTP 200.
