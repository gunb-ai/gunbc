# gunbc

A DSL-first workflow compiler where everything is a DAG.

## Install

```bash
git clone <repo>
cd gunbc
make install
```

Run `make help` to see all available targets.

## Overview

`.dag` files declare types, data, and workflows. The compiler lowers them to executable graphs.

```
Pipeline: .dag -> parse -> typecheck -> lower -> emit
```

Rust is the substrate -- it compiles, executes, and emits artifacts. Domain logic, policy data, and rendering live in the DSL.

| Path | Purpose |
|------|---------|
| `dsl/` | Primary authoring surface -- all `.dag` source files |
| `core/daglang/` | DSL compiler: parse, typecheck, lower, emit |
| `core/ir/` | Core IR types, patterns, transport model |
| `core/exec/` | Execution engine |
| `core/codegen/` | CLI and test generation |
| `lib/transport/` | Canonical I/O boundary |
| `gunbc-app/` | Repo-specific DAGs and CLI entrypoints |
| `docs/` | Design documentation |
