# Recipe: an uncommitted throwaway harness at src/v1/stage0/examples/m1c_bulk0_receipt.rs reads each touched
# file, runs the real v1 tokenizer -> parser -> annotation binder (v1_compiler_tokenize::tokenize_artifact,
# v1_compiler_parse::parse_with_table, v1_compiler_annotation_bind::bind_annotations), and prints one ROW line
# per admitted graph row plus a per-file REFUSALS count. The harness is not committed; this file is its output.
#
# WHY THE COMPILED SEED RATHER THAN AN INTERPRETED .dag PROBE. M1C-1's precedent ran the identical call chain
# through `gunbc run` over a .dag probe. That path is memory-blocked in this container: every attempt, down to
# an eight-file input, was SIGKILLed by the external ~5 GiB limiter after compile.analyses completed, so the
# receipt could not be produced at all through the interpreter. The harness calls the same functions in the
# same order — src/v1/stage0/src/v1_compiler_annotation_bind.rs is the regenerated realization of
# src/v1/annotation_bind.dag, and the seed is verified against its source by regen_stage0 --verify in this same
# change — so it executes one authority through its compiled realization rather than a second implementation.
# The interpreted route is the stronger evidence and is what a future pass should use once it fits in memory.
#
# JOIN AGAINST tools/m1c_bulk0_manifest.tsv, computed over (file, subject, first line) multisets:
