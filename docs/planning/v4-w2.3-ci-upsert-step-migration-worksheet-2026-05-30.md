## §1.2 Dual-authority dissolution (`CiJob` / `CiGate`)

`CiJob`/`CiGate` are **compatibility carriers** during W2.3, not semantic authorities for step selection or cache.

**Dissolve live-projection / retire 🟡 interim when all three hold:**

1. `ci_selection_receipt_shadow` (and active receipt path) consumes **`CiUpsertStep` row bodies** (inputs + projections), not step ids alone.
2. **T-22 eval** can interpret `CiUpsertStep` verify/create/resolve projections for step outcomes.
3. **W2.4 / Phase 1b** atom migration for a step no longer reads `CiJob`/`CiGate` for that step's semantics.

Until then: dual rows allowed; new work must not add **third** parallel step vocabularies.
