replace the counts in [`REMEASURE_1ed02057a5.md`](REMEASURE_1ed02057a5.md).** Those are ref-stamped
observations, and rewriting them into member sets would substitute a later derivation for what was
actually measured — the same move as a count copied off the current tree standing in for an oracle.

## Why the symbol alone is not the identity

Measured on the published 154-site partition: **154 sites → 99 distinct `(module, symbol)` pairs.**
33 symbols carry more than one site (the largest, `v2.compiler.eval :: eval_computation_node`, holds
ten), and one symbol spans **two different roots**. Two consequences a bare symbol set hides:

- *"Two lanes found the same symbol"* would not mean they found the same defect.
  Cross-lane overlap detection is the whole point of identity-keyed reporting, and a join that
  manufactures false agreement is worse than the fraction it replaces — a fraction at least
  announces that it is a summary.
- A symbol spanning two roots cannot be assigned to a root at all.

The normalized `expected -> found` relation restores exactly what the symbol drops. It is also the
most stable field measured here: it survived a 63-commit gap and two different rustc builds
unchanged.

## The bridge, stated as a rule

Other lanes reporting sites in **emitted** Rust need the same mapping back to authority names.

### 1. Module — read the declaration, never transform the filename

Every emitted file carries its authority on line 2:

```rust
// Generated by v1 compiler -- do not edit.
// Source module: v2.lens.coverage
```

The tempting textual rule — replace `_` with `/` — is **ambiguous and silently wrong**.
`std_realization_schedule.rs` is `std/realization_schedule`, but nothing in the filename
distinguishes that from `std/realization/schedule`, because module segments contain underscores
themselves. It works on whichever cases you happen to check.

### 2. Symbol — top-level items only

Take the nearest enclosing `fn`/`struct`/`enum`/`type` **at column 0**. Anything indented is
emitter-generated.

**This half exists because of a measured failure.** Taking the nearest enclosing item — the obvious
rule — returned `v2_lens_coverage :: CACHED` for thirteen sites. `CACHED` is the `thread_local`
static the emitter writes inside *every* data-definition function, so thirteen distinct authority
symbols reported as one name, presenting as a tidy one-symbol-thirteen-site cluster that no reviewer
would question. Restricting to column 0 yields the thirteen real symbols
(`coverage_defect_discriminant_predicate`, `coverage_defect_degenerate_type`, …), one site each.

`CACHED`, `__m`, `__sorted` and their siblings are **collisions by construction, not identities** —
the codegen mints the same name at every site by design, so the collision is guaranteed rather than
accidental.

### 3. Then attach the relation and the root

Per the identity above.

### The rule under both halves

**Prefer the declaration the producer wrote over a name you can reconstruct.** The header is
declared; the filename transform is reconstructed. The top-level symbol is authored; `CACHED` is
generated. In both cases the reconstructed form is the one that silently merges things that differ.

## One methodological constraint on reproducing this

Line-to-symbol resolution is **positional**, so sites must be symbolized against the emit tree from
**their own ref**. Symbolizing one ref's sites against another ref's emit mis-assigns names — the
same rot that disqualifies `file:line` as an identity. This artifact was produced by rebuilding at
`1ed02057a5` and re-emitting there, rather than reusing an emit tree already on disk from a
different ref.
