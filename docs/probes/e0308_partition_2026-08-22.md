## Raw rows → canonical sites

- **128** — raw `error[E0308]` blocks (what the probe histogram counts).
- **154** — canonical mismatch sites.

Blocks < sites because one `arguments to this function are incorrect` block carries one
`expected …, found …` per wrong argument. Two collapses run the other way and both are *unit*
corrections, never deltas:

1. **One mismatch printed two ways.** rustc's caret label elides deep generics
   (`Coverage<Rc<...>>`) while the block's `= note:` prints the same type in full
   (`Coverage<Rc<CoverageDefectAcceptanceKey>>`). Counting both inflates 13 coverage sites to 26.
   The classifier drops an elided pair only when a non-elided pair in the *same block* matches it
   under `... → .*`.
2. **One type printed two ways.** `im::Vector<T>` and `Vector<T>`, `std::string::String` and
   `String` are one type; module-path noise is normalized before dedup.

Sites are keyed on `(file, line, col, {expected, found})` — the pair is direction-insensitive,
because rustc prints both orientations of one mismatch when it reports a closure's argument and
its expectation.

### The grouping key is the delta vector, kept beside the pair

The classifier derives, per site, which axes differ — `rc_depth`, `nominal`, `generic_arg`,
`container`, `borrowed`, `optionality` — and stores that vector in its own TSV column **beside**
the derived cluster, never folded into it. So is the callee note (`callee`, `callee_kind`). This
is the direct correction of the 2026-08-21 `RT-builtin` failure, where `note: function defined
here → v1_rt.rs` was consumed into the root label and the population could not afterwards be
re-adjudicated into wrong-callee-selection versus correct-callee-wrong-signature.

## What this run does not establish

- **No cluster is a root.** Every row above is a candidate. Only an intervention — change one
  modeled decision, rerun the whole board, observe the exact conversions — promotes one.
- **A zero is not a repair.** T2 and B3-at-tokenize are masked by an earlier E0599 in the same
  file; RT-builtin left E0308 for E0061. Both are stated as conversions, not closures.
- **Old counts are not differenced against new ones** except where a mechanical cause is named,
  because the prior partition had no committed classifier.
- **M=1.** These are `03_ingest`'s closure. Per-module boards are overlapping closures and may not
  be summed with another module's.
- **The brief's 182 is not reconciled**, only reported as unreproduced with its two corroborating
  agreements (T2=0, T3=14) stated beside it.
- **No emitter decision was traced.** Cluster names come from pair plus callee evidence; no
  authored-decision count is offered.
