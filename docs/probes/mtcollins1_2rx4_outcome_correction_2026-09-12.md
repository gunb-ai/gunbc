# Correction: Mt. Collins 2Rx4 outcome, 2026-09-12

**Retraction:** `9e74a6b5262` called the prediction at `a28843d3180` falsified because “the group trains.” Initially observed were 373 seconds without a restart, memory power 10.4/9.6 W, temperatures 44/38 C, `Boot_Progress`, and the `12c805000000`/`12c805004000` pair. That right-censored interval contradicts a restart within the covered window; it does not establish training or contradict eventual failure.

**Causal limit:** exchanging quartets changes individual objects and their attributes. The quartets came from different orders and sellers; shared used-market origin is not a common lot. Their differing behavior narrowed the configuration, not the cause. Micron's numbering distinguishes dual-die `DS` from 3DS `PS`; `MTA36ADS2G72PZ-2G1A1` must not be forced into a 3DS catalog row. The historical two-arm stacking model could not represent that distinction.

**Subsequent readbacks:** the one-shot boot override changed from valid EFI/CD before reset to invalid/no override afterward, supporting boot-device selection. This still supplied no inventory or capacity receipt. The census image reported only over an unproductive SOL channel; share output and host network reachability were absent.

**Stronger observation:** the operator's KVM showed the Linux EFI stub booting a kernel, failing to load initrd with `0x8000000000000001`, generating an empty DTB and exiting boot services. Executed code establishes usable trained memory for that boot, not recognition or qualification of every installed DIMM. It reproduces the earlier boot-delivery failure after media was reported attached, weakening the reset-before-ready hypothesis; a larger-read failure remains unproved. A prior successful census makes the route intermittent.

**Instrument correction:** SOL repeatedly returned only its banner while KVM displayed host output. Console silence was never established. The later [firmware capture](mtcollins1_dram_training_root_cause_2026-09-12.md) identifies the repaired collector and bounds the mixture finding. The original observations remain evidence; their retracted interpretations do not.
