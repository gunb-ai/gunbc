## Root classification — three families, not scattered

635 errors reduce to **three mechanistic roots** (+ two small tails):

### Root 1 — missing `Clone` bound on generic type parameters (261, 41%)

`failure_shape=missing_method`, `method=clone`, receiver `type parameter T|A|U|B|R`.

Emitted generic fn bodies call `.clone()` on a type parameter without a corresponding
`where T: Clone` (or `A`/`U`/`B`/`R`) in the emitted signature. This is the direct
E0599 spelling of the same defect loyal-raven flagged for E0277.

### Root 2 — same missing `Clone`, bounds-unsatisfied call shape (329, 52%)

`failure_shape=bounds_unsatisfied` on:

- `is_empty` / `iter` for `Rc<im::Vector<T>>` and `im::Vector<T>` (168)
- `clone` for `Outcome<T>`, `Outcome<U>`, `Option<T>`, `im::Vector<…>` (161)

Rust reports "the method exists, but its trait bounds were not satisfied" instead of
"no method named …" — same underlying missing element/`T: Clone` propagation, different
surface error. **Roots 1+2 are one fix axis: generic Clone-bound propagation at emit.**

Combined R1+R2 in census TSV: **590 / 635 = 93%** of the bucket.

### Root 3 — modeled `Optional` coproduct matched on `std::option::Option` (24, 4%)

`GlobalBareUnique` / `GlobalBareAmbiguous` variant names on `Option<T>` / `Option<_>`.
Emitted code pattern-matches `Some(Optional::GlobalBareUnique { … })` but the receiver
is native `Option`, not the modeled `Optional` coproduct. Present in all six deep modules
(4 errors each); absent from `materialization_carriers`. Separate from Clone — this is
coproduct-native grounding (namespace-resolution / Value::Null family).

### Tails

- **as_deref on `()`** — 12 across six modules (2 each); wrong receiver type at a
  projection site, not Clone-related.
- **misc** — 9 (e.g. `Verdict<Subj,T>`, `CacheLookupResult<T>` clone bounds); only in
  modules that carry cache/verdict carriers.

## Verdict

**Not scattered.** 93% is one trait-bound propagation family (Clone on generic type
parameters and their `im::Vector`/`Outcome`/`Option` uses). 4% is a second, independent
Optional-coproduct grounding defect. Fix should be two slices, not seven per-module patches.

## Proposed fix slices (diagnosis only — no code yet)

### Slice A — generic Clone-bound propagation (target: −590 E0599, collateral −~180 E0277)

**Where:** v1 seed emitter generic fn signature / where-clause emission; v2 agnostic
predicate declaring which modeled operations require `Clone` on which type parameters.

**Mechanism:** When emitted body (or inferred use-site) calls `.clone()`, `.is_empty()`,
or `.iter()` on `T` or `im::Vector<T>` / `Rc<im::Vector<T>>`, emit `T: Clone` (and
`A`/`U`/`B`/`R` as needed) on the enclosing generic item. Same construction-predicate
shape as `wrap_decision_predicate` (#6776) but on trait bounds, not Rc-wrap.

**Measured target:** E0599 635 → ≤45 (tails only); per-module clone/is_empty/iter histogram
goes to zero on all seven. Collateral: E0277 `T: Clone` rows should burn in parallel.

**Coordination:** loyal-raven-94 (E0277). clever-eagle-187 only if measure-carrier serde
bounds intersect — not indicated by this census.

**Discriminating RED:** a generic fn that calls `.clone()` on `T` without `where T: Clone`
must refuse at the v2 predicate layer once landed.

### Slice B — Optional coproduct grounding for GlobalBare* (target: −24 E0599)

**Where:** emit path that lowers modeled `Optional::GlobalBareUnique|GlobalBareAmbiguous`
match arms — currently reaches native `Option` pattern syntax.

**Measured target:** E0599 −24 on six deep modules; `GlobalBare*` rows absent from census.

**Coordination:** namespace-resolution lane; not clever-eagle / vivid-raven / witty-wolf
ownership paths.

### Slice C — as_deref / misc tails (target: −21 E0599, defer)

Below the "one construction predicate" bar until Slice A lands; revisit if tails remain.
