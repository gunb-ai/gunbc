**Purpose:** record unit 1's population and load-backed EDAC observation, then separate those results from the boot-delivery failures encountered acquiring them. This is historical evidence from PR #10965, not a fleet purchase order or a current operating procedure.

**Owners:** `gunbc.machine_intake.mtcollins1_memory_census_observation` carries artifact identities/digests, population, channel bindings, unit identity, workload, controller samples and acquisition/consumption frontiers. `test.claim.machine_intake.mtcollins1_memory_census_witness` cross-joins the independent readings. Raw captures remain unchanged, including the upstream-published factory credential; future collection must use the modeled private-file route rather than copy argv credentials.

**Population:** Linux SMBIOS and boot-firmware inventory agree through the Ampere GSG channel map. The unique part position, independent rank sequence and populated connector set discriminate the join; no physical silkscreen observation is claimed. GHES firmware-first EDAC exposed a synthetic controller without a csrow topology, so firmware supplied channel membership. Per-unit rank/width/density fill requirements derive from `extdeps.ocp.mt_jade.memory_mixing`, not from copying the installed sample. Different-channel rank remains unspecified; this unit cannot qualify other machines or establish a fleet roster.

**Health:** counters were read before and after a named workload with repeated data digests, avoiding an idle-zero verdict. That bounded workload discharges the recorded intake question, not endurance, thermal qualification or `MemoryAuthoritativeQualify`. `HistoricalAdHocCapture` explicitly records the missing reusable producer.

**Boot distinction:** varying the legacy/EFI boot-type axis while holding persistence fixed changed a failed CD selection into a successful census boot. It establishes neither persistence policy nor the cause of the separate initrd-load failure after GRUB/kernel execution. The old handoff's accepted override/reset was not observed host boot. PXE service was absent on the measured segment; the working delivery route was NFS-backed BMC virtual media.

**Controller evidence:** session allocation preceded the observed status transition; raw statuses were never an authorized readiness decoder. Media-setting HTTP 500 occurred both with and without the desired readback, so HTTP success/failure alone carried no configuration verdict. The measured start-media request required `image_redirection`; general applicability remains unproved. Reset acknowledgment preceded actual disappearance, and IPMI returned before the web stack; observation must distinguish those phases.

**Corrections retained:** redirection-status “decay,” session-flag-as-count and all-failures-share-one-cause claims were withdrawn. Digest agreement did not validate a mistyped timestamp; preserved files did not prevent reused attempt identity. Persistent override was cleared at session end. Concurrent control, self-matching process kills and premature recovery polls contaminated attempted measurements. The later [collector correction](mtcollins1_dram_training_root_cause_2026-09-12.md) further limits inferences from SOL silence. Protocol/boot-policy repairs belong to their modeled owners; this record does not prescribe them.
