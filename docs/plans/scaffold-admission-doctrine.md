# Scaffold admission doctrine

*Authority: admission rulings extracted from DESIGN.md §5 on 2026-08-18; operator ruling 2026-08-10, receipt gunbc#8073. This file owns the verdict vocabulary, external approval and actuation exception. [Original wording](https://github.com/gunb-ai/gunbc/blob/06d3c1c3149a7420c4a548b9aba9b15c721c635d/docs/plans/scaffold-admission-doctrine.md).*

**Default: finish the final construction.** A dissolution condition describes how admitted debt ends; it does not authorize creating it. A current head introducing net-new active dissolution obligations without an explicit operator verdict on that exact population is a hard reject. Unmarked debt adds concealment. Finish the underlying model, decomposition or generation; temporary work is an exceptional admission, never the ordinary alternative.

Price temporary work as authoring, review, maintenance, deletion and deletion review against its lifetime benefit. If the modeled path already exists, the temporary path buys no benefit.

**Lifecycle is separate from admission.** A bound condition has a checkable trigger; an unbound condition honestly cannot report itself fired. Neither proves justification. `std.disposition.Scaffold` supplies a construction mechanism and declaration binding, not authorization, necessity, benefit or assessment of an available final path.

The verdict is one of:

- `RejectAndFinishNow`: build the sustainable path in this PR; the default.
- `ApproveTemporaryIntroduction`: admit this exact new temporary construction.
- `AcknowledgePreexistingDebt`: record debt already on the base; admits no new debt.

**Approval is observed outside the diff:** the configured operator's APPROVED review, bound to the current head and invalidated by any later push, presented with the exact derived new-obligation set. An authored approval row cannot approve itself.

One obligation covers one independently removable unit. Artifacts may share it only if they have the same terminal construction, fire on the same observation and cannot survive one another.

**Out-of-band actuation has no ordinary scaffold option.** Hand-authored workflows, deploy/migration scripts or manual mutation paths beside a modeled actuator are manual application committed as source. They do not refine into the modeled intent→generated plan→host-effect route; they are replaced whole. Mainline admits the modeled path or nothing, except an explicit operator ruling bound to the current head.

Branch-local experiments may run and produce measurements, but their disposable implementations must be deleted before merge, leaving modeled facts. In #8073, all three hand-authored Spark workflows beside the fleet convergence spine were deleted; a registered Scaffold did not admit them, and its disposition lost its subject when they disappeared.
