# Print request convergence

**Goal:** realize one physical copy per request without replaying an uncertain start. `gunbc.fleet.print_request` derives standing from evidence; `print_converge` takes one action per pass. Preparation, approval, starting, reconciliation and acceptance remain separate.

**Method:** prepare from the selected assembly, committed plate and named recipe without printer credentials/contact; create the request record binding source, project digest and attempt. Then use only `printer_actuation.start_authorized`: exact-version credential, fresh report, signed attempt/artifact/credential/state-bound bed-clear grant, exclusive controller and durable attempt claim before upload; recheck readiness/expiry before one publication. Claimed jobs are observed, never resent. Completion binds the exact job and the same report that established its standing; malformed/mismatched records refuse. Another copy requires another request.

**Preparation authority:** `product.printed_chassis.print_preparation` consumes one assembly selection, CAD/STEP/manifest identity, pinned slicer and snapshotted profiles. It validates full membership, transforms, geometry/keepouts/bed fit, archive/checksums, settings, AMS, warnings, deposited bounds and support policy. Supplied XY packing is a candidate while Orca auto-arranges; extra plates refuse. Print-plane preservation remains mandatory until qualified departures exist. Support paths are separately attributed and digest-bound; commanded centerlines are not measured plastic. Preparation recomputes per request; no reuse obligation is declared.

**Runtime:** `product.printing.print_runtime.observe_print_runtime` owns the observed OS/packages/architecture, exact CAD interpreter and runnable pinned Orca, producing `PrintRuntimeReady`. Preparation only observes. Explicit `print_workflow.converge_runtime`/`provision_and_run` provisions the same requirements, with private digest-named environment, exclusive publication, probes and a ready marker. Unpublished/mismatching environments refuse; transitive dependencies are not fully locked. Historical manual package installation remains a process error, not retroactively modeled work.

**Start boundaries:** readiness accepts only the modeled IDLE/FINISH states and exact vendor error exception; these never establish an empty bed. The report fingerprint cannot detect ABA, so no manual printer operation is allowed during pending approval. Unread/active/paused/error states, absent persistent claim storage, wrong host or expired grant refuse. Only printer federation plus signed ntfy approval authorize starts; retired token-file/batch paths are not alternatives. Never remove a claim to retry an uncertain publication.

**Readback:** bounded post-start reconciliation retains fresh raw reports and requires exact attempt filename, RUNNING and nonblocking numeric error in one report. No display-name fallback, merged/cached delta or FINISH confirms running. Nonzero publication remains uncertain; wrong/partial reports consume observation budget without republishing. Success also requires cleanup success. Preserve claims on uncertainty. Printer FINISH and zero error cannot prove physical acceptance or detect spaghetti.

**Validation:** `test.claim.printer_batch_workflow_validation.validate_preparation` exercises real approval identity, production preparation and archive/G-code negative controls without printing. `test.claim.print_preparation_kernel_validation` covers the shared process observer, integrity and retrospective output. `observe_process_batch` writes fresh digest-named observations, never authorizes prints. Retraction/commanded-motion evidence retains unknown feed, startup scope, inherited-setting uncertainty and unavailable actual layer time; it proves neither cooling, island count nor a stability threshold. Physical inspection, adhesion/stiffness, loaded-joint/creep/thermal qualification and live controller evidence remain separate. Historical preparation checks are not current CI or live-release receipts.
