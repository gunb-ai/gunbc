# Runner-throughput qualification recut

**Goal:** assess independently selected capacity without minting the offer or permission being assessed. The operator's source hold on #11722 requires selection before convergence and classifies runner registration, dispatch and deregistration as control-plane writes.

**Method:** `SelectedRunnerQualification<P>` receives the offer, executor sanction, requirements, pinned workload/specimen, conserving selected host-plan receipt, selected slot, sampling policy and phase ceilings. The assessment never calls allocation policy to manufacture these inputs. The control-plane charge must already be included.

`ObservedRunnerQualificationRun` is producer-minted and sealed: host/program/revision/specimen, image/runtime/toolchain, slot unit/incarnation, effective systemd/cgroup bounds and budget resolution, measured peak, observed workspace locus, phase readings and run/time identity. Copying selection into observation is forbidden. Sealed `RunnerThroughputAssessment<P>` first joins subject identities and effective bounds, then aggregates each axis: minimum throughput/width, maximum peak/phase wall, unread dominating. Exactly-one versus minimum-run conservative sampling is selected policy, not an internally chosen slowest run. Required-phase membership must be exact; walls adjudicate only selected ceilings. The claim covers interpreter rate and slot memory envelope, not unassessed floor-step counts.

**Admission home:** extend existing `product.fabric.node_qualification.OfferDeliveryClaim<P>` with `OfferClaimsRunnerDelivery { offer, assessment }` and its existing refusal vocabulary; `claimed_delivery_check` requires exact selected-offer identity before `admit_delivered_offer` applies sanction/policy. No parallel runner admission fold or caller-authorable admitted receipt. The selection adapter's separate module records a measured seed import-resolution boundary, not a new permission authority.

**Route:** `StageEffect` distinguishes BMC writes, GitHub control-plane writes, guest-local work and observation. Every effectful leg is bound or explicitly awaiting authority; an unbound route is not executable. Registration/dispatch/deregistration retain exact attempt/slot identity.

**Cut:** remove the old sanction/offer-minting qualification/admission root, `HostBudgetFacts`, copied receipt constructor, single-run selection and false `NoControllerWrite` classification in one replacement. Re-home useful per-axis standings, observations, argv/slot projections and frontiers; the original declaration table provides exact dispositions. The consumer is the existing fabric admission, not an independent checker. Retain operator/owning-manager review of the recut before implementation.

**Validate:** foreign host/program/specimen/revision, wrong cgroup/effective bound/backing, direct construction, incomplete/duplicate phase roster, sanction mismatch and oversubscribed host plan must refuse. A faster second run exceeding memory cannot be hidden by a slower passing run. No runs/unread bounds/low throughput/unbound effect remain refusing. Exercise the actual fabric consumer and wrong-offer binding with bounded witnesses and current required checks. Retire this plan only after the types/claim/consumer and bound route land, and a real mtcollins1 run mints the observation and dissolves its frontiers.
