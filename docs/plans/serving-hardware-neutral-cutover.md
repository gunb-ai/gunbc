# Hardware-neutral serving cut

**Goal:** route an arriving turn through a loaded replica collection whose device count and model artifact are data. Re-home generic serving folds under `gunbc.serving.*`, preserving the [separate serving occupancy contract](serving-capacity-home-ruling.md). This plan does not execute the operator's cutover decision.

**Replacement:** `harness_seat.harness_bind_seat` is the consumer-relative root. Generic deployment selection, vLLM launch/process identity, observation and load/performance folds move once; Spark hardware/GLM/RoCE facts remain Spark rows. The old pair/Ray deployment is retired, not a live cohort to generalize; disposition surviving native-GLM helper consumers individually. Freeze Spark topology growth while its live rack remains on the old route.

**First complete cohort:** rented one/two-device RTX PRO 6000 Blackwell inventories, Qwen as the first generic model row, one replica per fitting device. Missing inventory/model admission, unread gauges or per-device non-fit refuse; no implicit tensor-parallel packing. Reuse existing selection, serving admission, launch/observe and capacity algebra. Every new declaration must feed the actual seat binder and qualification path.

**Warm-session contract:** preserve replica ownership across rounds/tool gaps and when adding replicas. Bind warmth to exact launch identity and token-prefix continuation; distinguish context loss, process replacement and reconstruction. Declare normal continuation's bounded replay/reuse and verify observed cache counters. vLLM still owns allocation; missing backend capability stays a gap. Replica identity must key capacity, acquisition, front-door permit and release consistently; derive collection capacity from members.

**Consumer census required at deletion:** inspect `harness_seat`, `harness_backend`, `harness_cli`, `harness_reasoning_wire`; serving enrollment/front door/availability/engine progress/admitted model; CI receipt paths, fabric-capacity instrument, frontend evaluation, runner posture, workspace-demo policy, fleet image build, store admission and node/superchip qualification. Re-enroll surviving claims with identity-level `EvidenceDisposition`; retire obsolete claims explicitly. The original table names their import edges. Required emitted closures do not cover this root: green required CI alone cannot expose omissions. Also repair docs, runbooks, ledger/rung-drop references that will not fail compilation.

**Transition:** build the replacement in shadow on an integration branch, then switch each complete cohort's authority once. Rented turns must never resolve through Spark dispatch. No adapter, feature flag, fallback or dual interpretation of one turn. The live Spark rack waits until the replacement holds its unified-memory/four-rank boundary; inability to do so is a real incomplete cohort, not permission for a leafwise migration. Escalate for the owning operator's cut admission before deleting production authority.

**Validate:** use an actual growing agent-session trace through the admitted binder, not only random-prefix load generation. Exercise tool gaps, full context envelope, pressure admission, lost-warm-state recovery and addition of a replica without moving sessions. Bind latency/completion/sustainable-load evidence to the performance subject and repeat unchanged for each inventory. Terminal: no old consumers of migrated contracts, undispositioned/uncovered consumers, production adapters/fallbacks or migration flags. Preserve old measurements only as offline evidence.
