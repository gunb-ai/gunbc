It was never a live receipt in the first place: the suite was gated by `cargo test --no-run`, so the *green by execution* this paragraph claimed had not been observed since that gate landed — and when the cutover finally ran the module it reported 53 passed / 3 FAILED in 1321s, over the gate's 15-minute budget. The carriers now say so: the `warm-hit-skips-semantic-recompute` clause in `gunbc.materialization_kernel_closing_frontier_audit` reads `NotDelivered`, and `gunbc.ci_cost_arc_closeout_receipt` `warm_hit_settle` = `SkipProofWithdrawn`.
