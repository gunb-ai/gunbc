# Interchangeable power cassette

**Goal:** select power independently of node cassettes, with a common protected node interface and replaceable PSU-specific inserts. Default to one PSU; redundancy needs justified incremental cost and documented single-module behavior. This is a reference architecture, not released electrical/CAD hardware.

**Method:** `product.printed_chassis.server_power_interface.pairing_screen` binds each node to one named supply/branch and checks unique identities/assignments, interface compatibility, branch and aggregate capacity at the selected AC input, overhead and reserve. Outputs are never implicitly paralleled. `node_power_feed` owns board-side inputs; `stack_mass_review` owns declared load examples and placed-mass screens. Assignment changes require rerouting and a new stack analysis. Capacity passing does not qualify the assembly.

Each mechanical insert owns cage/envelope, retention, ventilation, cord strain relief and withdrawal clearance; each electrical adapter owns its exact matched PDB, pinout, enable/sense/standby, sharing/ORing, management and protected harness. Keep the vendor mains enclosure and protective earth intact. A station controller owns shared enable; never tie host PS_ON outputs together or connect unverified standby to a signal header. Evaluate a branch fault against upstream shutdown.

**Node interface:** accessible shrouded/keyed/locking DC, local isolation/status, and the selected Ethernet policy from [assembly requirements](cassette-assembly-requirements.md). Select actual connector ratings, wire/crimp system and mating life; shell similarity does not establish EPS/PCIe compatibility. Shut down/isolate before disconnecting. Hot-swappable PSU modules do not qualify live board mating. Future blind mating requires alignment, sequencing, inrush/precharge/discharge and interlock, not a printed latch assumption. Keep service access outside stack joints and extraction paths.

**Candidate limits:** FSP800/1200 complete assemblies are references, not required suppliers. Input-dependent main-rail ratings, redundant failure capacity and exact envelope come from the cited variant; reconcile conflicting catalog/drawing dimensions before CAD. PH51A's custom-harness offering is not an included multi-node harness SKU. Chicony R550AV02P specifications do not qualify the seller's S550E004L. Installed Mt. Collins module/PDB identity remains to be observed. PMBus is not a universal power/mechanical interface.

**Validate:** obtain exact part/drawing/harness and single-module enable/airflow evidence; select coordinated branch protection and connector; evaluate overload/failure, startup, cable reach, thermal exposure and retained enclosure. Fold complete masses/placements into statics, then review CAD and an unpowered prototype. Printed material, wiring, protection and powered-operation obligations remain open even when the numeric screen passes.
