164	// Execution, invoked here through `sh -c` rather than by name), present wherever a POSIX-conforming
165	// shell is -- unlike `which`, an EXTERNAL BINARY (part of debianutils on Debian/Ubuntu, not part of
166	// POSIX or a base busybox install) that may be absent on stripped appliance images, BMC firmware
167	// shells (Dropbear), or minimal containers. This operation's own assumption is not unconditional
168	// either: it still requires a POSIX shell at `sh` on the target's PATH. gunbc.fleet.fleet_intent's srv1-4
169	// ComputeHost, and gunbc.ci.ci_fleet's own CI/falsifier runner, both carry an `OperatingSystemSurface
170	// { distro_or_product: none, ... }` -- no distro or package-set authority anywhere in this fleet,
171	// our own runner included (crisp-wren-896 finding, PR #8590; the modeling gap is named at
172	// std.os.types operating_system_surface_package_authority_gap_note). This operation's assumption
173	// strictly dominates `which`'s -- every target that can run `which` can run `command -v`, and the
174	// converse fails on busybox and stripped images -- which is why the former shell.Which.Check
175	// operation was deleted rather than kept as a second, narrower-scope choice (crisp-wren-896, PR
176	// #8590): a selection rule between two operations is only worth its cost when each is right
177	// somewhere the other is wrong, and here nothing was. If even the POSIX-shell assumption cannot be
178	// established for a target, the honest realization is a typed refusal, not a silent fall-through
