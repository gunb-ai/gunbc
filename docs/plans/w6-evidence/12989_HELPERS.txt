// rm(1) — GNU coreutils, "Removing files or directories". Three shapes are used in this
// repository and the distinction between them is load-bearing, not stylistic: -f removes a file
// and does not fail when it is already absent (idempotent teardown); -d removes an EMPTY
// directory and REFUSES a non-empty one, which is a fail-closed precondition rather than a
// weaker rm -r; -rf removes a tree. Choosing -rf where -d was meant turns a loud refusal into
// silent destruction, so the three carry separate names rather than a flags parameter a caller
// fills in.
