# D13 Network audit — which extdeps operations reach the network

Input to D13 step (b) (`gunbc.plans.demand_engine_program`, rung drop `gunbc.rung_drop` `network_requirement_unrepresented_after_uses_cut`). Selection rule (from the step-(b) owner): an operation reaches the network iff executing it Wet **necessarily** opens a connection to a non-local endpoint. It is judged from the operation's own declaration (transport kind + argv/endpoint) against the cited upstream behaviour. Only `Network` rows get a `requires Network` clause (`std.resources.Network`).

Population: every `operation` under `dag/extdeps` (no `src/v2/extdeps` file declares a service): **520** operations — Network **272**, NotNetwork **236**, OpaqueDemand **12**.

## Selection rule as ruled (quiet-seal-543, 2026-10-01)

The ruling supersedes the brief's "necessarily". A `requires` clause states what a sandbox must GRANT, so the fail-closed direction is to over-declare: an operation that **may** reach the network counts as Network. The 53 rows first classed Undecided were ruled as follows:

1. **A url/remote parameter is Network**, including `http.Client` `GetLocalhostBounded`. An operation name is not a type: until its `{url}` is typed loopback it can reach anything, so it is listed as a candidate for loopback typing.
2. **A program parameter is OpaqueDemand** (`shell.exec` Run*, `systemd-run`, the sudo probe `Check`, `gunbc.WitnessBin` `Run`, and the node/python/go `RunFile` runners). These rows get no clause in .dag, but that is not "no demand": the argv is runtime data the derivation cannot see, so step (b) must yield DemandUndecided (a refusal) for their callers.
3. **Cache-dependent fetches are Network**: cargo without `--offline`, `npm ci`, `npm cache add`, `npx -y`, `apt-get install`, `gcloud auth print-access-token`.
4. **`arping` is Network**: it uses the network interface.

The ssh/scp/`-I lanplus`/`https://{bmc_host}` classing was confirmed as Network. The section below records the first-pass reading; each ruled row carries its ruling in its citation.

## First-pass reading rules

- **rest**: Network when the service endpoint resolves to a non-loopback host. That covers every HTTPS API base and the GCP metadata server (`metadata.google.internal` = 169.254.169.254, which is link-local, not loopback). The Docker Engine rows bind `unix:///var/run/docker.sock` (`extdeps.docker.endpoint` `docker_default_endpoint`), so they are NotNetwork. `github.OIDC` `GetToken` declares no endpoint (it uses a runtime `request_url`), so it is Undecided.
- **file**: NotNetwork.
- **shell → Network**: the argv fixes a network protocol to a host — `ssh`/`scp`/`sshpass … ssh`, `ipmitool -I lanplus -H {bmc_host}`, `curl https://{bmc_host}…`, `curl https://api.github.com/…`, `gh api|pr|run`, `gcloud auth login`, and hosted-model CLIs in prompt/exec mode (`claude -p`, `codex exec`, `gemini -p`).
- **shell → Undecided (PARAM)**: the declaration fixes neither scheme nor host. Examples: `curl {url}` (could be `file://` or loopback), `git fetch|push|ls-remote {remote}` (a remote may be a local path), Playwright `goto {url}`, and runtime programs (`shell.exec`, `systemd-run … command_argv`, `{bin_path}`, script runners). The brief's example list calls `curl` to a URL and `git fetch/push` Network. This audit holds them Undecided anyway, because the declaration leaves the endpoint to a parameter, which is the case the brief's own Undecided rule covers. Ruled above.
- **shell → Undecided (STATE)**: whether the network is used depends on local cache state, not on argv. This covers `cargo build|check|test|…` without `--offline`, `npm ci` without `--offline`, `npx -y`, `apt-get install`, and `gcloud auth print-access-token` (which refreshes only on expiry).
- **shell → Undecided (RULING)**: `arping` sends link-layer ARP frames but opens no connection.
- **Everything else** runs a local program on local paths (coreutils, local git verbs, systemctl/journalctl, `ip` over netlink, the tailscale LocalAPI behind `serve status`, …) → NotNetwork.

Each row names the operation by module / service / operation symbol and cites an upstream doc or man page section.
