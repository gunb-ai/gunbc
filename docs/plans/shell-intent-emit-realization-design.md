# Language-blind intent

**Goal:** remove raw shell and language-construction authority from workflow intent. Intent is the ordinary typed `.dag` dependency graph; `Pipeline` is optional sugar. The finish line is every raw-concatenated shell site correctly realized and the old String command leaves unconstructible from intent, not merely absence of `bash_build`.

**Ownership:** interfaces own dependency semantics; workflow policy supplies parameters; target-parametrized emission owns syntax; realization owns host effects and transport selection. Runtime-present sites use typed services/effect plans directly. Only roster-bounded foreign-executor/bootstrap windows emit shell through grammar rows. [`v2.std.execution_surface.authorize_shell_emission`](../../src/v2/std/execution_surface.dag) owns that routing; [effect orchestration](../../dag/gunbc/plans/host_effect_orchestration.dag) owns `Do{effect}`; [residual census](shell-to-dag-residual-census-and-arc-completion.md) owns site dispositions. No duplicate inventory here.

**Construction:** intent imports no language-building vocabulary, and domains import no tool vocabulary. CLI-backed handlers alone lower semantic operations through cited CLI grammar; native REST/filesystem/library handlers need no argv carrier. Local process argv is not shell text; SSH's command string is a distinct target, not an argv prefix. Moving concatenation into flags or embedded programs does not remove the misplaced authority.

**Config follows the same rule:** one emitter mechanically renders modeled facts and knows no business concepts. Toolchain isolation, cache keys, action components and permissions must derive from their owners, not special cases in workflow emission. Config-literal construction checks are a separate missing wall from shell containment.

**Existing enforcement and remainder:** `realization_vocabulary_containment` and `meta_exec_confinement` constrain imports. `TransportScript` sealing, its admitted production mints and cast checks close a separate construction route; the raw-literal backstop remains. The admitted bridges' String body inputs still require per-site migration. An empty import-exception roster does not establish that remainder closed. Replace/migrate all consumers before deleting the load-bearing command/bootstrap carriers, under current DESIGN replacement doctrine and the owning lane's cut review; the legitimate bottom shell transport remains sequestered.

**Validation:** exercise a domain operation through native REST without CLI/argv/shell, and the admitted foreign-executor path through grammar emission; reject intent vocabulary leaks, unauthorized sealed construction and config facts detached from their authorities. Multi-target Python remains a modeling litmus until multi-handler dispatch exists. Pure text/collection work belongs in `std`, not a fake coreutils catalog; shell-backed realizations share one cited quoting authority.

**Exemplar:** deploy-preflight is a runtime-present authorization query over shared grants/principal evidence, realized as typed effects before mutation. The concat/Pipeline emitter was removed; sudoers materialization remains roster-derived. Broader mutation leaves belong to the census, not a new grant vocabulary or another emitter. Current source owners, not the dated milestone labels, decide what remains implemented.
