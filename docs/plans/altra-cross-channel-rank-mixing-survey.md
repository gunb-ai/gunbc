# Altra cross-channel rank mixing: unresolved publication evidence

**Goal:** establish whether Altra/Altra Max permits cross-channel 1R/2R DIMM mixing. **Method:** compare publisher population rules and their exact axes. **Validation:** an explicit Ampere rank rule, an updated OCP cell, or a responsive vendor answer. The 2026-09-11 survey (swift-bat-341, `node://adhoc-d3527d08-755`) found neither permission nor prohibition; it does not admit the running configuration or settle the purchase.

`extdeps.ocp.mt_jade.memory_mixing.mt_jade_mixed_dimm_support_table` owns the only explicit cell: Rev1.0 §7.4 Table3, Different Channel × Mixing 1R & 2R = **TBD**. Other surveyed documents do not answer that rank question.

- Ampere Collins GSG1.05 p10 and Jade PVT/DVT NVMe GSG1.00 p11 require identical DIMM **capacity within a socket**, allowing sockets to differ. Equal-capacity 1R/2R modules satisfy that sentence; it does not decide rank. `extdeps.ampere.mt_collins_product_brief.memory_population` carries the rule. The observed unit1 uniform-capacity population satisfies it; mixed capacity would be a separate enforceable violation.
- Altra Family AVL1.15 (Dec2025) tests homogeneous 1DPC/2DPC populations. It lists HMA82GR7CJR4N-VK (16GB 1Rx4), not unit1’s HMA82GR7CJR8N-VK (16GB 2Rx8, #11066). A fill using the listed single-rank sibling removes both the unlisted-module and mixed-rank questions; AVL membership alone is not a mixing rule.
- Search and Wayback CDX found only Jade Rev1.0. The OCP contribution database returned403 and its mailing-list search was inaccessible: no later revision was **found**, not proved nonexistent. Mt. Mitchell v0.80 is DDR5 and supplies no DDR4 answer.
- Board guidance is not SoC authority: Gigabyte R272-P30 recommends matching capacity/brand/speed/chips; ASRock ALTRAD8UD requires identical groups for eight-channel use (brand/speed/size/chip type); neither explicitly identifies rank. Supermicro R12SPD-A recommends matching type/size/speed and allows mixed speed, but this survey read a mirror and requires publisher reread before citation. Wiwynn SV328R publishes no population rule; Foxconn evidence added none beyond Ampere’s guides.
- Forum threads564/3309 do not isolate rank: the same generic “Non-identical DIMM mixture” summary followed capacity mismatch in one and unsupported CAS latency/bad identical modules in the other. Clean EDAC under load on unit1 is a gunbc observation, never an extdeps fact or published approval.

Datasheet device-width/density/channel features and hardware topology are not population-rank rules; apparent firmware enforcement remains observation until documented.

No new extdeps declarations land without a consumer. If needed, SoC memory/interleave facts belong to their datasheet/specification owners; a modeled capacity rule can cite both independent GSGs. Resolving rank requires the explicit upstream answer above, not more inference from capacity, chip width, AVL absence or successful local operation.
