# Determinism is emergent and boundary-relative: the honest rung and its closed-denominator trigger

*Provenance: this lane was carried as an Open Threads row in `DESIGN.md` until 2026-08-18, when that section was deleted on operator ruling — `DESIGN.md` is a first-principles document and per-lane status in it was a dual representation. `v2.std.determinism` — **mechanically preventive for uniquely named registered roots; not repository-wide structural determinism** (honest rung correction, 2026-08-01). Determinism is emergent and boundary-relative (built on `std.perturbation`; a leak carries a `DeclarationRef` to the root reached, not a label enum), and `v2.lens.determinism.determinism_compile_gate` — enrolled in `v2.compiler.compile` `always_required_root_lenses` — refuses the two uniquely named Map projections whose traversal order is host-unspecified: `map_keys` and `map_values`. The former mechanism registered only `map_keys` and asserted it was the one readable nondeterministic atom; that premise was false because `map_values` exposes the same host iteration and was silently classified deterministic. The generic aliases `keys` and `values` remain undetectable: the lens sees only an unqualified callee `Symbol`, v2 `Node` carries neither receiver domain nor resolved declaration identity, and method/free-call lowering erases the distinction; registering either symbol would wrongly refuse unrelated same-named functions. Absence from the root list is therefore **not evidence of determinism**, absence of a diagnostic does not establish that no order-exposing operation was reached, and a newly introduced but unregistered operation is not detected. The attainable ceiling is explicit: the primitive subject universe is forked across `v1.compiler.infer_method` `builtin_function_registry`, `std.primitives` `PrimitiveContract` rows, `std.algebra` templates, native `v1_interpreter` dispatch arms, and per-target emit handlers. This is reachable rather than theoretical: `fold_list` is abundant in compiled v2 trees and has a native interpreter arm while appearing in neither the algebra Map surface nor the builtin registry; `index_by` has a writable native map-producing arm and a `PrimitiveContract` while likewise outside both. A closed denominator cannot be assembled by adding another partial roster. Dissolve-on: the `PrimitiveDefinition` identity join closes the denominator, disambiguates aliases, and gives roots resolvable identity by naming invocation forms, receiver domain, parameters, result, realization, and cost once; then every operation has exactly one traversal-order classification, unclassified refuses, and unsafe roots derive from that one authority. The x2 sampling emit gate remains deleted (#6551 · #6576 · #6594); authority is the carrier (`dag/std/determinism.dag`, `src/v2/lens/determinism.dag`), not this receipt. Prefer preserving meaningful source order in a separate list while using a map only for membership (the corrected PR #7515 pattern); there is no universal `sorted_map_values` order.
