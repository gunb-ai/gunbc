## §3. Failure-mode catalogue (per-target)

This section unpacks the emitted-source failure modes by emitter pattern, so downstream consumers (SUPPORTED.md authors, README review, dispatch managers) can name the specific emit-lens bug without re-running the verification:

### §3.1 Python — `examples_weather.py`

| Site | Failure mode | Emitter category |
| ---- | ------------ | ---------------- |
| line 56: `return match cond:` | match-as-expression emitted where Python requires statement-level `match`; `return` cannot take a `match` block as a value in standard Python | match-expression-lowering missing in Python emit |
| line 68: `return high_f = to_fahrenheit(...)` | `:=` walrus assignment emitted as `=` in return position; even with `:=` Python forbids `return assignment` semantically | assignment-expression-vs-statement confusion in Python emit |
| `freezing_locations` comprehension | Broken comprehension shape (specifics per merry-bear's transcript: needs follow-on grep) | comprehension-lowering bug |

### §3.2 Go — `examples_weather.go`

| Site | Failure mode | Emitter category |
| ---- | ------------ | ---------------- |
| `return switch cond {` | Go `switch` is statement-only; `return switch` is not legal Go | switch-as-expression-lowering missing in Go emit |
| `return highF := …` | Go `:=` is statement-level only; `return highF := …` is not legal Go | short-var-declaration in return position |
| `panic()` in case arms | Likely fallthrough modeling — case arms emit unreachable `panic()` where Go expects no fallthrough or explicit `break`/`return` | case-arm-control-flow lowering |
| Undefined `v2rt` refs | References to a runtime package that isn't emitted alongside the artifact | missing runtime-package bundle in Go emit |

**Note:** the same conceptual emit-lens bug (match-/switch-as-expression vs statement) shows up in both Python and Go, in different syntactic clothing. This is a single upstream modeling gap (expression-vs-statement lowering for control-flow constructs) projected through two language emit lenses. Tracked as a Compiler Spine / Target Realization concern; this Close/Receipt lane only catalogues, it does not dispatch the fix.
