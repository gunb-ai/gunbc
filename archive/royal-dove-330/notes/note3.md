A5. THE REMAINING EQUALITY CHECKS
E1 PREDICTED-DIFF MATCH. `git diff --name-only` after any wet act must be exactly one file, `.github/workflows/witnesses.yml`; its line-set diff must equal §7's six hunks exactly (stamp literal at line 25; locate-step name; BASE_SHA line; 26 widened `if:` lines; reuse-walk `if` unchanged; publish-walk `run:` gaining ` --reuse-from .`). Any extra hunk — a reorder, an added/removed step, another workflow touched — is a STOP and a re-review. §7 is labelled EXPECTED precisely so this comparison is falsifiable.
E2 STAMP IS RECOMPUTED, NOT MERELY PRESENT. The committed literal must equal `compiler_gate_contract_stamp` recomputed from the REGENERATED YAML. A guard that only checks "the committed stamp is non-empty" would pass a stale stamp (your point, made explicitly). I verified why it cannot silently pass in the ordinary case: the stamp steps recompute from the checked-out YAML and `parse_verdict_pre_build_guard` refuses StampMismatch/StampAbsent before the compiler build — so a wrong stamp makes main RED rather than quietly green. That is a RED-on-main argument, NOT a regeneration-correctness argument; the A3 dry gate is the correctness argument.
E3 IDEMPOTENCE. Run the actuator twice on the same binary and seed; outputs must be byte-identical (sha256 pair recorded). Non-idempotence means hidden nondeterminism and invalidates every other equality claim.
E4 CROSS-EXECUTION AGREEMENT (provenance, the part §7 cannot supply). A SECOND execution — different binary build provenance, different machine if available, same seed and subject sha — must produce the same bytes. Two independent executions agreeing is what "generated, not hand-edited" means; one execution agreeing with my prediction only means "the generator and my reading agree".
E5 HAND-EDIT EXCLUSION. The file stays reachable only through the A1 chain: CommitRequired (generated_artifact.dag:233), the pre-push contract-stamp guard (compiler_gate_workflow.dag:623), the qualification floor embedding the stamp into job identity (:589-612), and the A3 drift gate. Stated as READ FROM SOURCE, not verified by running.
